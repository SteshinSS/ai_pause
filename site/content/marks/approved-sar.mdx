Notice how the more capable model, SAR, has fewer AI safety years than the less capable AC.

That happens because, at AC, the model isn't capable enough for our verification protocol, so we instead use it as an engineer with human researchers in the lead. We still need to verify the final results (thus Results Verification), but here we allow AI to run arbitrary code without prior human approval. It's not a recommendation, but one of the possible protocols.
